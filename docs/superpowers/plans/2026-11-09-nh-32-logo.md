# NH-32 Logo and Menu-Bar Icon Implementation Plan

**Goal:** Replace the placeholder logo and the `mic` menu-bar symbol with the winking, tongue-out face.

**Architecture:** Two SVGs in `assets/` (colour logo, one-colour glyph). A dev script renders the glyph to committed 18 and 36 px PNGs in `Resources/`. `bundle.sh` copies them into the app and `buildMenu()` loads them as a template image.

**Spec:** `docs/superpowers/specs/2026-11-08-nh-32-logo-design.md`.

## Constraints and review focus

- No unit tests.
- A missing image falls back to the `mic` symbol.
- The image is a template with alpha, so dark menu bars work.
- `codesign` still runs last in `bundle.sh`.

## Task

1. Spec's SVGs go in `assets/`.
2. `scripts/render-menubar-icon.swift` renders the glyph to both PNGs.
3. `bundle.sh` copies the PNGs before `codesign`.
4. `buildMenu()` loads the named image as an 18 pt template, else `mic`.
5. Verify with `swift build`, `swift test`, `scripts/bundle.sh`; the menu-bar look is a manual PR check.
