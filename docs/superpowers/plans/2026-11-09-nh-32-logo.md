# NH-32 Logo and Menu-Bar Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the placeholder logo and the `mic` menu-bar symbol with the winking, tongue-out face.

**Architecture:** Two SVG sources in `assets/`. A dev script renders the one-colour glyph to committed 1x and 2x PNGs in `Resources/`. `bundle.sh` copies the PNGs into the app, and `buildMenu()` loads them as a template image.

**Tech Stack:** SVG, Swift script run with `swift` (AppKit `NSImage` reads SVG on macOS 14), bash.

**Spec:** `docs/superpowers/specs/2026-11-08-nh-32-logo-design.md` (it holds the draft SVG for both pieces of art).

## Global Constraints

- Colour logo viewBox `0 0 64 64`, green `#059669`, tongue `#FB7185`, no text or fonts.
- Glyph viewBox `0 0 18 18`, one colour with alpha, PNGs 18 by 18 and 36 by 36 px.
- File names: `assets/icon.svg`, `assets/menubar-icon.svg`, `scripts/render-menubar-icon.swift`, `Resources/MenuBarIcon.png`, `Resources/MenuBarIcon@2x.png`.
- Menu text beside the icon, `imagePosition` and `refresh()` stay unchanged. Swift 6 strict concurrency stays on.
- No unit tests (spec § Testing; `AGENTS.md` excludes menu-bar layout and framework behaviour).

## Review Focus

- The image is missing (unbundled `swift run`): the menu bar still shows the `mic` symbol.
- Dark menu bar and accent tint: the image is a template (`isTemplate = true`), so it is not a fixed black shape.
- Rendered PNGs keep their alpha, with no white or black background square.
- `codesign` still runs last in `bundle.sh`, after the PNGs are copied.

**Interfaces:**
- Consumes: nothing from earlier tasks.
- Produces: the bundled app holds `Contents/Resources/MenuBarIcon.png` and `MenuBarIcon@2x.png`, found by `NSImage(named: "MenuBarIcon")`.

- [ ] **Step 1: Write the art.** Put the spec's colour SVG in `assets/icon.svg` and the spec's glyph SVG in `assets/menubar-icon.svg`, both copied as drafted. The preview sheet is `docs/superpowers/specs/2026-11-08-nh-32-logo-preview.png`.
- [ ] **Step 2: Write `scripts/render-menubar-icon.swift`.** Run as `swift scripts/render-menubar-icon.swift`, from any directory (resolve paths from `#filePath`). It loads `assets/menubar-icon.svg` with `NSImage(contentsOf:)` and draws it into an `NSBitmapImageRep` with alpha at 18 and 36 px with high interpolation, then writes `Resources/MenuBarIcon.png` and `Resources/MenuBarIcon@2x.png`. Exit non-zero with a message if the SVG fails to load.
- [ ] **Step 3: Run it and check the output.** Run `swift scripts/render-menubar-icon.swift`. Run `sips -g pixelWidth -g pixelHeight -g hasAlpha Resources/MenuBarIcon*.png`. Expected: 18 by 18 and 36 by 36, `hasAlpha: yes`. Look at the 36 px PNG: the eye, wink, mouth and tongue show, and the corners are transparent.
- [ ] **Step 4: Update `scripts/bundle.sh`.** After the `Info.plist` copy and before `codesign`, copy `Resources/MenuBarIcon.png` and `Resources/MenuBarIcon@2x.png` into `$APP/Contents/Resources/`.
- [ ] **Step 5: Update `buildMenu()` in `Sources/NoHands/AppDelegate.swift`.** Replace the `mic` line with a small private helper `menuBarImage() -> NSImage` that loads `NSImage(named: "MenuBarIcon")`, sets `size` to 18 by 18, `isTemplate = true` and `accessibilityDescription = "NoHands"`, and falls back to `NSImage(systemSymbolName: "mic", accessibilityDescription: "NoHands")` when the named image is nil. `NSImage` is not `Sendable`, so keep it inside the main-actor class and don't weaken concurrency.
- [ ] **Step 6: README.** Line 1 keeps `src="assets/icon.svg"` and width 64, and `alt=""` becomes `alt="NoHands logo"`.
- [ ] **Step 7: Verify.** Run `swift build` and `swift test`; both must pass. Run `scripts/bundle.sh` and check `ls build/NoHands.app/Contents/Resources` lists both PNGs and `codesign --verify build/NoHands.app` exits 0. Do not launch the app. The real menu-bar check is manual and goes in the PR.
- [ ] **Step 8: Commit and push.** Commit `feat: winking logo and menu-bar icon (NH-32)`, ending with the Co-Authored-By line, and push `feat/nh-32-logo`.
