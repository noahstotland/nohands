Extend the existing decoder and grammar tables. The `scripts/intent-eval*.json` fixtures are not edited and must still pass offline checks.
3. **Mac probe, observer, executor.** `AudioOutputProbe` (CoreAudio, per-process `kAudioProcessPropertyIsRunningOutput` excluding own PID on 14.2+, device-wide fallback below, errors give false), injected into `ScreenObserver` by protocol (fake in tests). Fill `observation.media` in the task observe from collected elements (before the cap and untitled filter); probe only when no control. `ActionExecutor`: `.waitFor(.mediaPlaying)` polls every 500 ms on both harnesses, cancellable, "wait timed out"; `.checkMedia` adds a reading. Executor test for the wait.
4. **TaskRunner done check.** Play goal and `done` without failure: settle and observe once. `paused` the first time gives history failure "not playing yet" and continues; `paused` again or the step cap gives `stuck("not playing yet")`; `playing`/`none`/nil is done. Non-play goals untouched. One table test in `TaskRunnerTests`.
5. **README.** Voice table row for the three phrases; `observe` and `snapshot` CLI rows mention the media line (and the CLI prints it if it prints observations).
