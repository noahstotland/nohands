# NH-98 `pack new`: Implementation Plan

> **For agentic workers:** use subagent-driven-development or executing-plans, task by task.

**Goal:** `nohands-cli pack new [--app <name|bundle id>] [--out <file>]` reads the app's top-level menus and writes a draft pack file that passes `PackFile.parse`, listing what it left out. It never installs.

**Architecture:** Pure `PackDraft` and `MenuShortcut` in `NoHandsCore` (reasons for left-out items come from `PackFile.parse` on a one-command pack); `MenuShortcutReader` over a `MenuNode` protocol (AX implementation plus a fake in tests) in `NoHandsMac`; CLI wiring in `Sources/nohands-cli/main.swift`.

**Spec:** docs/superpowers/specs/2026-11-16-nh-98-pack-new-design.md (source of truth for ids, phrases, reasons, errors, CLI flags)

## Global Constraints

- Swift 6 strict concurrency; no `@unchecked Sendable`, no `@preconcurrency`; no AppKit/network in NoHandsCore.
- Add `shortcut: KeyChord? = nil` to `MenuEntry`; every current caller stays unchanged. Do not change `AXMenuReader` behavior.
- Do not restate validator rules: probe each candidate with `PackFile.parse` on a one-command pack (valid placeholder id, e.g. `probe-pack`) and use `PackError.reason`. Parse the whole draft once before writing.
- Never overwrite an existing file; never install; print app strings through `PackSummary.printable`.
- Test lines must not exceed feature lines; one table-driven test per rule (AGENTS.md § Testing); no test needs Accessibility, the mic or a model.

## Tasks

1. **MenuShortcut + MenuEntry.shortcut (core).** `MenuShortcut.chord(char:virtualKey:modifiers:) -> KeyChord?` per the spec's mapping. Table test.
2. **PackDraft (core).** `PackDraft.make(appName:bundleID:entries:) -> (pack: AppPack?, data: Data?, leftOut: [LeftOut])`. Id rule, phrase rule, action choice, left-out order and reasons per spec (including already-a-NoHands-phrase via `CommandGrammar(packs: PackSet([AppPacks built-ins]))`-style parse for the bundle ID, and `IrreversibleGuard.held` with empty goal). Table test; every produced draft re-parses after `PackFile.encode`.
3. **MenuShortcutReader (mac).** `MenuNode` protocol, AX implementation (`kAXMenuItemCmdChar`, `kAXMenuItemCmdVirtualKey`, `kAXMenuItemCmdModifiers`, 2 s / 1500 items), `noMenuBar` error. Fake-tree test.
4. **CLI.** `pack new` in `packCommand`: flags, 3 s wait without `--app`, running-app lookup by name or bundle ID, messages from the spec's error table, file write (0644, no overwrite), summary and `pack add` hint. Update usage text.
5. **Docs.** `docs/app-packs.md` (§ Write a pack) and `docs/cli.md` row. No voice table change.
6. Verify: `swift build`, `swift test`. Manual checks go in the PR (Safari draft + `pack add` + a phrase; Finder lists Empty Trash as irreversible).

## Review Focus

Draft always passes the validator; left-out reasons match the validator's; shortcut mapping (no-command bit, no char); id collision with built-ins; terminal escapes from menu titles; no overwrite; `AXMenuReader` unchanged.
