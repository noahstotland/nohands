# NH-33: A full-colour app icon: Plan

**Spec:** [2026-11-09-nh-33-app-icon-design.md](../specs/2026-11-09-nh-33-app-icon-design.md) (approved)
**Ticket:** [NH-33](https://github.com/noahstotland/nohands/issues/33)

No unit tests (spec § Testing). Verification is `swift build`, `swift test` and the bundle checks in Task 3.

## Task 1: Source art

Create `assets/app-icon.svg` and `assets/app-icon-small.svg` with the spec's two drafts, byte for byte. Done when `swift scripts/render-app-icon.swift` (Task 2) reads both without error.

## Task 2: Render script and icon

- Create `scripts/render-app-icon.swift` in the style of `scripts/render-menubar-icon.swift` (same header comment, `#filePath` root, `fail()` helper, `import AppKit`).
- It loads both SVGs with `NSImage(contentsOf:)`, draws each size into a transparent RGBA `NSBitmapImageRep` of exact pixel size, and writes a temporary `.iconset` in `NSTemporaryDirectory()` with the 10 standard names (`icon_16x16.png` through `icon_512x512@2x.png`).
- 16 px comes from `app-icon-small.svg` with no shadow. Every other size comes from `app-icon.svg` with this shadow, scaled by `size / 1024`: blur 28, offset (0, -12), black at 30% alpha.
- It runs `/usr/bin/iconutil -c icns <iconset> -o Resources/AppIcon.icns`, fails with a clear message on a non-zero exit, and removes the temporary folder.
- Run it once and commit `Resources/AppIcon.icns`.
- Done when `iconutil -c iconset Resources/AppIcon.icns -o <tmp>` gives 10 files and the 16 px file is 16 by 16 (`sips -g pixelWidth`).

## Task 3: Wire into the bundle

- `Resources/Info.plist`: add `CFBundleIconFile` = `AppIcon` (next to `CFBundleExecutable`).
- `scripts/bundle.sh`: copy `Resources/AppIcon.icns` into `$APP/Contents/Resources/` with the other resources, before `codesign`. Do not touch the `codesign` line.
- Done when, after `scripts/bundle.sh`: `build/NoHands.app/Contents/Resources/AppIcon.icns` exists, `plutil -extract CFBundleIconFile raw build/NoHands.app/Contents/Info.plist` prints `AppIcon`, `codesign --verify --deep --strict build/NoHands.app` exits 0, and `swift build` and `swift test` pass.

## Task 4: Docs

`README.md` needs no change unless the documenter finds a stale line (the "no Dock icon" sentence stays true). Mark the spec `**Status:** Shipped` with the `**Shipped:**` line as part of the closeout docs in the PR (open-pr § Closeout docs).
