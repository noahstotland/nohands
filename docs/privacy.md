# Privacy

What leaves the Mac and what stays. Back to the [README](../README.md).

- Audio never leaves your machine.
- Only commands the grammar can't match go to Claude (or the local model, which stays on your Mac), as text: your transcript, the frontmost app's name and its controls' titles.
- Task steps also send the window title, the page URL (in a browser), each element's role, and a `Media:` line (`playing`, `paused` or `none`) read from Play or Pause buttons or whether another app makes sound.
- With agent-desktop, each listed field's current value (cut at 60 characters) is sent; clipboard text, a full element value and notifications only after the model asked to read them. Text handed to it (`set_value`, `type_into`, `clipboard_set`) is visible to `ps` while it runs.
- The plan request sends only your transcript.
- **Follow-ups.** A follow-up like "no, the other one" (within `followUpWindowMs` of a task) also sends the earlier request, its last 8 step summaries, how it ended and the app, window title and URL it ended on. Held in memory only, never logged; `followUpWindowMs` `0` turns it off.
- **Rewrites.** The rewrite commands (`make that shorter`, `fix the grammar`, `translate that to French`; see [Voice commands](voice-commands.md)) send the text you selected, or the last sentence before the caret when nothing is selected (at most 2,000 characters), the instruction (a fixed sentence, or your own words for `rewrite that <words>` and the language for `translate`) and a fixed system prompt, and nothing else: no app name, window, URL, rest of the field or picture. They go only to the configured backend: Claude over HTTPS, or Ollama on `127.0.0.1`. Nothing is sent when the text is refused or no field is focused. The rewrite's own log line carries only the backend, the kind of instruction, character counts, milliseconds and token counts, never the text, the answer or your words. The selected text and the answer are never logged or written to disk. The utterance log line holds the spoken phrase under the private marker, like every command, and so keeps what you said (your own words for `rewrite that <words>` and the language for `translate` are part of that) and the character counts.
- Without an API key nothing is sent off the Mac; with the local backend, text goes only to Ollama on `127.0.0.1`.
- **Routes.** A task that ends `done` after at least two clean steps is saved to `~/.config/nohands/routes.json` (folder mode 700, file mode 600, replaced atomically), up to 50 tasks. Each holds your goal as the task got it (cut to 300 characters), the host of the last page it saw (`espn.com`), and each step's intent and actions by name: the title of the element clicked, an app or menu item name, a site, or a web address's host and path with the query and fragment dropped. Text you typed or searched for, and a question's answer, are cut out of the saved step wording (any text of 3 or more characters, in any case), and the file never holds element lists, screenshots, page text or failures. A step's wording is the model's own sentence, so it can still paraphrase what you said, and element titles, or a web address's path, can still be things like an email subject that was clicked or a topic you searched for. Your goal is saved as you said it. Routes saved while on the local backend go to Claude with later matching tasks if you switch backends. The file is read once at launch and never sent anywhere by itself. When a later goal matches, that route's steps (not the file) go to the configured backend with each step of the task, as data in the request. Follow-up memory is separate: it lasts 30 seconds, in memory only, and a follow-up neither gets nor saves a route. A task that asks you a question saves the question only, never your answer. To clear it, say "forget that route" (the route the last task was given and the one it saved) or "forget all routes", or quit NoHands and delete the file. `routeMemory` `false` turns it off and leaves an existing file alone.
- **Command log.** The last 50 commands go to `~/.config/nohands/command-log.json` (folder mode 700, file mode 600, replaced atomically): what you said and what was typed or clicked. Never sent; delete the file to clear it.
- **Screenshots.** With `visionFallback` on, pixels leave the Mac only on the task steps in [Multi-step tasks](tasks.md#multi-step-tasks), only to Claude, never the local model; nothing is captured when the backend is local or the flag is off. The picture is the focused window only, so it can show text, messages and passwords. Held in memory, never saved, not logged.
- **There is no wake-word model.** Everything the microphone hears is acted on; `attentionWord` makes command mode ignore speech that doesn't start with it. Other people, a phone on speaker or loud playback can still be acted on or, in dictation mode, typed. Say "go to sleep" before leaving the desk or during calls; only "wake up" is honored while asleep.
